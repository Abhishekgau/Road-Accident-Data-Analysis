# Road Accident Data Analysis & Interactive Dashboard

## 📌 Project Overview
This project analyzes comprehensive road accident records to uncover key trends, temporal patterns, high-risk conditions, and casualty metrics. An interactive **Excel Pivot Dashboard** was built to deliver data-driven insights for safety evaluation and stakeholders.

## 📊 Key Dashboard Insights
- **Casualty Metrics:** Tracks total casualties alongside breakdowns for Fatal, Serious, and Slight accident severities.
- **Vehicle & Road Factors:** Evaluates which vehicle types and road classifications account for the highest volume of casualties.
- **Temporal Trends:** Analyzes year-over-year casualty comparisons (CY vs PY) and monthly fluctuation spikes.
- **Environmental Impact:** Highlights lighting conditions (Daylight vs. Darkness) and urban vs. rural area distribution.

## 🛠️ Tools & Technologies Used
- **Microsoft Excel:** Data organization, cleaning, and preprocessing.
- **Pivot Tables & Pivot Charts:** Aggregating metrics and building dynamic data models.
- **Advanced Dashboard Design:** Custom side navigation layout, KPI scorecards, and interactive filtering panels.

## 📂 Repository Structure
- `Road Accident Data.xlsx`: The underlying dataset containing detailed accident records.
- `.gitattributes`: Configuration settings for tracking large files using Git LFS.
